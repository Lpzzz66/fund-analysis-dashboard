# 私募基金估值分析看板前端

这是正式前端入口：React（前端框架）+ TypeScript（类型语言）+ Ant Design（界面组件库）+ Vite（构建工具）。业务数据只从后端接口读取，后端唯一业务数据源是估值 Excel（电子表格）。

## 本地运行

```bash
npm install
npm run dev
npm test
npm run typecheck
npm run build
```

开发服务器把 `/api` 和 `/health` 转发到本机后端 8000 端口。生产构建结果由 Caddy（网页服务器）提供，浏览器通过同源 `/api/v1` 请求后端。

## 页面边界

- 看板、产品列表、产品详情、风险事件只展示后端已发布或已落库的数据。
- 导入、复核、邮件接入和管理页面的写操作均调用真实接口；成功后重新读取服务器状态。
- 原始 Excel 下载只允许从导入批次详情进入，并经过后端鉴权、审计和路径安全检查。
- 邮箱授权码只提交到后端，成功后输入框清空，前端不保存、不展示明文。
- 清理原始文件必须先执行预演，再输入固定确认短语和操作原因；数据库标准化数据与审计日志不删除。
- 未有真实接口或数据支撑的策略、基金经理、基准、版本差异、映射试跑、风险试算、邮件附件导航等功能不在正式页面承诺。

## 权限

普通看板只读；业务员可上传、复核发布、维护产品/科目/风险规则和执行邮件运营；系统管理员另可维护账号、系统设置和原始文件清理。最终权限以后端接口鉴权为准，前端按钮隐藏不是安全边界。

`src/mock` 目录仅作为早期视觉原型归档，不被任何生产页面、路由或接口适配器引用，也不参与正式业务运行。
